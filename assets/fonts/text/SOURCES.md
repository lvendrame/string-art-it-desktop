# Font sources

All fonts below are sourced from the [Google Fonts](https://github.com/google/fonts) repository (`ofl/` directory), licensed under the SIL Open Font License 1.1 (`OFL.txt` in this folder). Each family ships `Regular.ttf` + `Bold.ttf` (where available) + `Italic.ttf` (regular weight only — no combined Bold+Italic files are included, to keep the file count manageable).
